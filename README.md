# Earth Data Challenge 2027

Course website for EEPS 5000 Special Topics: Earth Data Challenge at WashU.

The site is plain HTML and CSS, with no build step or runtime dependencies.
Preview from this directory with `python3 -m http.server 8000`, then open
`http://localhost:8000/`.

## Editing

- `index.html`: course information, schedule, resource links, and contact.
- `styles.css`: shared layout, typography, colors, and responsive styles.
- `ai-workflow.html`, `coding-guidelines.html`, `using-git.html`: student guides.
- `assets/`: map-tiles artwork and downloadable course poster.

## GitHub Pages

The intended repository is `washu-eeps/EDC-2027`. Publish the root directory of
the approved publishing branch through GitHub Pages. Relative links support the
project path `/EDC-2027/`; `.nojekyll` serves the files without Jekyll processing.

## Artwork

The map-tiles illustration was generated with the built-in image-generation tool
for the EDC 2027 poster. It is conceptual artwork, not an observed dataset or a
scientific map. The banner and poster reuse that illustration. Poster source
is maintained in the EDC 2027 course workspace.

## Course source

The schedule follows the instructor-approved course plan and the
[WashU academic calendar](https://registrar.washu.edu/calendars-exams/academic-calendar/).
The resource topics continue the [2026 course](https://washu-eeps.github.io/EDC-2026/),
with team collaboration guidance adapted for individual GitHub accounts.
