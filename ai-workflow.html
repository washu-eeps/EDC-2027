AI-assisted research

Use AI tools throughout a project while documenting the analysis and checking the results.

Where AI can help

  • Scoping: frame a question, check feasibility, and define what would answer it.
  • Data access: discover relevant cloud-hosted datasets and investigate access methods.
  • Coding: implement, debug, and document notebook code in small steps.
  • Interpretation: explore alternative explanations and identify possible failure modes.

What teams document

  • A version-controlled repository with a notebook that runs from beginning to end.
  • Data sources, analysis steps, and environment requirements.
  • A short record of major AI-assisted decisions and prompts.
  • Checks appropriate to the analysis, including units, expected ranges, simple comparisons, and limitations.

How teams check the work

Run code, inspect intermediate results, and compare outputs against a known result or a published reference. Confirm dataset names, APIs, and methods against their sources. Students must be able to explain the code and reasoning in their own words and attribute external code and sources.

See the coding guidelines for a practical workflow and the WashU AI resources for university guidance and tools.

Asking for debugging help

Read the traceback and identify the code cell that failed. If using an AI tool, provide the error as text and ask for the smallest fix. Check the suggestion, try it, and use the observed result to guide the next step. Remove credentials and private information before sharing code or errors.

When asking the instructor for help, include the traceback as text, the relevant code, and what you tried. Screenshots are useful for visual problems such as a map that does not display correctly.
