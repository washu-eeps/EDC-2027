Agentic coding

Students plan. Agents implement. Students validate.

No prior Python or programming experience is required. Coding agents write and debug the implementation. You decide what analysis to do, check what the agent produced, and explain the results.

Students plan

Before asking an agent to implement an analysis, write a short plan:

  • What scientific question are you asking?
  • Which data will you use, and what are their limitations?
  • What comparison or calculation will answer the question?
  • What outputs do you need?
  • How will you check whether the result is correct?

An agent can help you develop the plan. Your team decides which methods and assumptions to accept.

Agents implement

Give the agent your plan and ask it to implement a small, runnable example. Review the output before extending the analysis. Ask the agent to explain processing steps, diagnose errors, and revise the code when a check fails.

Require the agent to ask before changing the dataset, method, filtering rules, or scope. Keep code and documentation in your team repository. Review changes before accepting them, and keep credentials and private information out of prompts and repositories.

Students validate

Inspect the actual data and outputs. Check units, coordinates, dates, missing values, and whether inputs line up. Compare a small example with a known result, a published reference, or a calculation you can check separately.

An agent can write tests and suggest checks. Its assurance that the code works is not evidence that the analysis is correct. Check that the tests address your scientific question and inspect what they actually returned.

Restart the notebook kernel and run the analysis from beginning to end. Explain what the result supports, what remains uncertain, and where the workflow could give misleading results.

Repeat when a check fails

Describe the discrepancy, ask the agent to investigate it, and examine the revised result. Keep the scientific question and validation criteria in view as you revise the plan or implementation.

What to submit

  • Your analysis plan and data sources.
  • A runnable notebook and instructions for reproducing it.
  • The checks you performed and what you observed.
  • Your interpretation and the limitations of the result.
  • A brief record of consequential agent-assisted decisions.

You should be able to explain the major steps and scientific reasoning. You do not need to write Python syntax from memory.
